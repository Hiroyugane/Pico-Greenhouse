# Repository layout

Annotated file tree. For what the modules *do* together, see the architecture
section of [`readme.md`](../readme.md#how-it-works); for what every knob means,
see [`configuration.md`](configuration.md).

## Root

```text
config.py         DEVICE_CONFIG + validate_config() — every tunable value, checked at boot
main.py           orchestrator: DI wiring, boot order, async task spawn, health loop
requirements.txt  host/dev dependencies (pytest, ruff, pre-commit, reportlab)
pyproject.toml    pytest, coverage and ruff configuration — single source of truth
readme.md         project overview
```

## `lib/` — application modules

Deployed to the Pico (or frozen into the firmware). No module here imports
`DEVICE_CONFIG`; values arrive through constructors.

### Regulation pipeline

```text
regulation_engine.py      the uasyncio tick loop that owns the pipeline and the actuators
regulation_normalizer.py  physical readings → deviation space (anchors, day/night blend)
regulation_surface.py     2D hinge surface evaluation — allocation-free, array('f') params
regulation_arbiter.py     bands, slew limiting, floors, conflicts, emergency, latch
regulation_adapters.py    commanded intensity → physical actuator; all device quirks live here
```

### Sensing and logging

```text
sht31.py                SHT31-D I²C driver, CRC-validated
temp_humidity_logger.py  T/H logger with date rollover; caches the values the engine reads
co2_logger.py            UART CO₂ logger — Modbus CRC, plausibility window, staleness
soil_logger.py           ADC soil-moisture logger with calibrated scaling (plant mode)
metrics_logger.py        one health + regulation metrics CSV row per health-check cycle
event_logger.py          system log with severity levels, buffered flush and rotation
sensor_paths.py          canonical /sd/sensors/<type>/YYYY/<type>_YYYY-MM-DD.csv builder
boot_log.py              file-backed mirror of pre-EventLogger boot diagnostics
```

### Storage

```text
buffer_manager.py       the single write chokepoint: SD → fallback file → RAM ring buffer
write_queue_manager.py  async SD write batching, keeps writes off the hot path
sd_integration.py       mount_sd() / is_mounted() helpers
```

### Hardware and actuators

```text

time_provider.py     TimeProvider / RTCTimeProvider — every timestamp in the system
relay.py             RelayController (active-low aware) and the relay-backed controllers
fan_output.py         RelayFanOutput, Pca9685FanOutput, NullFanOutput
fan_controllers.py   always-on fan policy (the case fan — the one actuator outside the engine)
pca9685.py           16-channel I²C PWM driver
mcp4725.py           12-bit DAC driver for the 0–10 V grow-light dimmer (vendored)
```

## `host_shims/` — CPython stand-ins

Prepended to `sys.path` by `main.py` when the runtime is not MicroPython.
Anything new that imports a MicroPython-only API needs a shim here, or it will
only ever run on-device. Never imported by the tests.

```text
machine.py       Pin, SPI, I2C, UART, ADC, WDT with console logging
micropython.py   const() stub
os.py            mount / umount / ilistdir / VFS stubs
framebuf.py      framebuffer stub for the OLED driver
uasyncio.py      aliases standard asyncio
sht31.py         SHT31 simulator mirroring lib/sht31.py
_probe_data.py   canned readings captured from real hardware
```

## `tests/` — pytest suite

`conftest.py` installs `MagicMock` stubs for `machine` / `micropython` /
`uasyncio` **before** any `lib/` import and patches the MicroPython time
idioms. Importing `lib.*` at a test module's top level bypasses that — import
inside the test or fixture, as the existing fixtures do.

```text
conftest.py      MicroPython mocking setup
README.md        how the mocking works and how to add to it
test_*.py        one file per lib/ module, plus config, main and the host tools
golden/*.csv     frozen input→output vectors pinning the regulation surface math
```

A deliberate surface retune must regenerate the golden vectors with
`prototypes/plot_regulation_surfaces.py`; an accidental one shows up as a
failing golden test, which is the point.

